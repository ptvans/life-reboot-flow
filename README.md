# Life Reboot Flow - Santa Cruz Move Decision Tree

Comprehensive visualization and planning system for complex relocation from Santa Cruz with multiple vehicles, storage locations, and financial constraints.

## Overview

This project provides an interactive decision tree, Gantt chart timeline, and financial analysis for managing a complex move involving:
- 6 vehicles across multiple locations
- 5 storage locations (Santa Cruz, Santa Rosa, Hayward, Monte Rio, Ace Vehicle Storage)
- Financial constraints (living on 0% APR credit cards)
- Health urgency (wisdom tooth surgery Jan 23)
- Housing urgency (hotel ends Jan 14)
- Job search while starting new business

## How to Use

1. **Open the visualization**: Open `index.html` in any web browser
2. **Navigate tabs**: Click through the 6 tabs to see different aspects of the plan:
   - **Overview**: Critical path summary and immediate priorities
   - **Key Decisions**: Major decision points with pros/cons analysis
   - **Timeline & Tasks**: Phase-by-phase Gantt chart with dependencies
   - **Vehicles**: Complete vehicle inventory and disposition plans
   - **Storage**: Storage location analysis and consolidation strategy
   - **Financial**: Monthly burn rate, expenses, and potential income

## Files
